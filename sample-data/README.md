# Synthetic sample data

Both workbooks contain invented marine-tour booking records. They intentionally include exact matches, naming aliases, field-level mismatches, missing records, and a duplicate reference. No operational or client data is included.

- `system-a-demo.xlsx`: primary source example.
- `system-b-demo.xlsx`: comparison source example.
- `detailed-system-a-demo.xlsx`: pricing-level primary source.
- `detailed-system-b-demo.xlsx`: pricing-level comparison source.

Regenerate both files with `python scripts/generate_sample_data.py`.
